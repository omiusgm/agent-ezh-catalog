# Agent Ezh — personal services for AI agents

Connecting an assistant to everyday tools is still difficult for a beginner. Agent Ezh provides small MCP integrations and repeatable guides for your own Telegram, email and other services, starting with read access and explicit consent for writes.

[Start here](docs/start-here.md) · [Machine-readable catalog](catalog.json) · [Russian](README.md) · [Community](https://t.me/agentezh)

Published packages: [Telegram](https://github.com/omiusgm/agent-telegram-setup), [Gmail and Yandex Mail](https://github.com/omiusgm/agent-mail-setup), [Bark notifications](https://github.com/omiusgm/agent-bark-setup), [Yandex Music metadata](https://github.com/omiusgm/agent-yandex-music). Additional guides and the honest prototype roadmap are linked from the Russian README.

An integration being published does not mean it is installed or authorized for you. The installing agent prepares dependencies; the account owner completes login locally. Secrets and personal data must never be pasted into a chat or Issue. Verify an actual allowed operation in the final client.

Bug reports, feature requests, translations and focused pull requests are welcome. No repository write access is required: fork and submit a PR. See [CONTRIBUTING](CONTRIBUTING.md) and [SECURITY](SECURITY.md). Current code and new catalog text are MIT; upstream projects keep their own licenses.
