# Публичные пакеты и разработка

Карта обновлена 3 ноября 2026. «Опубликован» означает наличие исходников и инструкции, а не автоматическую работоспособность на любой машине. Даты проверки конкретных пакетов указаны в catalog.json.

| Компонент | Состояние | Ближайший критерий |
| --- | --- | --- |
| Ёж Telegram MCP | Публичный пакет и локальный/серверный пилот | Простая установка и сквозная приёмка чтения/файла выбранным клиентом |
| Почта | Публичный пример Gmail/Яндекс | Повторяемая проверка нового владельца, затем больше локальных форм |
| Ёж Bark | Публичный пилот уведомлений | Доставка на конкретный телефон и правильная роль отправителя |
| Ёж Codex MCP | Личный прототип; публичного установщика нет | Надёжные сообщения, уточнения и остановка в исходных чатах |
| [Ёж Computer MCP](https://github.com/omiusgm/agent-computer-setup) | Публичный переносимый SSH-пилот; личный адаптер остаётся отдельным | Чистая установка новым владельцем и реальный вызов его агента с выбранными правами |
| Ёж ToDo MCP | Личный прототип трекера | Прямой доступ агентов и честные автоматические статусы |
| Ёж Agent Inbox MCP | Синтетический пилот, интеграция с трекером | Доставка, прочтение, повторы и восстановление; пока без файлов |
| Apple и iPhone | Личные пилоты | Раздельная проверка данных Apple и управления выделенным телефоном |
| ВК, Instagram, Авито | Исследование и ограниченные пилоты | Устойчивый вход и разрешённое чтение без обхода защиты |
| Маркетплейсы | Личный пилот | Поиск и выбранная корзина; оформление/оплата вне этого этапа |

Новые компоненты не получают выдуманные ссылки на ещё не существующие репозитории. В каталог установок они попадут после обезличенного пакета, лицензий, инструкции восстановления и проверки. Для нового пожелания откройте Issue; большой проект сначала обсуждается.

Общий приоритет — надёжный базовый контур и простой вход, затем новые сервисы. Отдельная панель статусов и ночной аудит пока идеи; действующий трекер остаётся основным интерфейсом.
