# Простой вход без скрытых доступов

Целевой путь: выбрать сервис и клиента → показать права → открыть штатный или локальный вход → проверить подключение → показать результат и отключение.

OAuth используется там, где его поддерживает провайдер и выбранный MCP. Вход в ChatGPT не заменяет авторизацию Telegram, ВК или почты. Если нужны API ID, пароль приложения или runtime-ключ, владелец вводит их локально в маскированной форме; агент не получает секрет через переписку.

Мастер должен показывать состояние каждого этапа, безопасно продолжать после перерыва, сохранять прежние разрешения и объяснять только необходимые действия владельца. Форма не хранит секрет в URL, истории браузера, аналитике или публичном отчёте. Headless-сервер использует отдельный проверенный способ ввода; нельзя просто опубликовать localhost-форму.

У Telegram уже есть локальный веб-мастер и учебные изображения этапов, у Bark — локальная форма ключа. Универсального установщика всех интеграций пока нет: сначала переиспользуем эти компоненты и проверяем чистую установку каждой интеграции.
